# Requirements Overview

## Goal

Веб-дашборд для конкурентного анализа — инструмент для визуализации и управления данными о конкурентах в рамках исследования рынка.

## Primary user

Один пользователь (автор проекта), запускает локально в браузере.

## Success criteria

- Данные о конкурентах отображаются в структурированном виде.
- Можно добавлять, редактировать и сравнивать конкурентов.
- Дашборд запускается локально без дополнительной инфраструктуры.
